5 · stop as soon as it is decided

Short steps, stop early

Each step adds one small batch and one row of numbers. After every row: can more steps still change the answer? If not, stop.

score after each stepsteps saveddashed = pass line

8 · who does what

Four roles

Lead agent

Picks the next need, writes the rules, hands out cards, merges.

Worker agent

One card, own copy of the code. Builds, runs the short steps, reports numbers.

Checker agent

Not the builder. Breaks the fix on purpose; the test must turn red.

Reviewer

A stronger model. Picks forks and any verdict change.

All four roles are written rules. A hook that watches hand-offs only logs; it does not block.
