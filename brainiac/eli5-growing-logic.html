How does brainiac learn to think for itself?

brainiac is a small computer brain that learns from text, the way a child learns from stories. Here is the plan to help it grow its own logic, and where it stands today.

Updated 2026-11-24 05:21 PST

The big idea

brainiac grows its own sentence and logic structures. Nobody types the skills in. The code gives it only brain parts: cells, links that get stronger with use, a surprise signal, a reward, replay, sleep, and a place to save. Then it reads stories. Reading makes new cells and new links. One brain file is never wiped; it keeps growing.

The 4 parts

A. Own logic structures

Means: brainiac builds its own kinds of thinking, not ones we code.

How: a ladder of 6 rungs: groups, compare, order and cause, not/all/some, if/then, question shapes.

Now: waiting. It starts after the sentence steps.

B. Forming sentences

Means: brainiac says more than one word, and says it well.

How: four steps. (1) Reading grows the brain (KB-3712). (2) Stories feed its piece store (KB-3720). (3) It learns how sentences start (KB-3726). (4) It leans toward topics that paid off (KB-3728).

Now: step 1 is running; the final check is not in yet. In the last read, a copy fed 29 stories grew by 11,201 cells; a copy fed nothing stayed flat. Steps 2 to 4 wait. Today only 3 of 65 replies are 3 or more words that name the thing.

C. Story elements

Means: a retold story names who, where, and what happened, in order.

How: the order-and-cause rung plus a who/what/where rung. A new check (KB-3798): retell or continue a story naming a character, a place, and 2 events in order.

Now: waiting. The check is written down, not run.

D. Asking questions, and how to ask

Means: brainiac notices what it does not know and asks, in a good question.

How: it asks itself first (KB-3738); that counts only if the answer makes a later answer better. Then it asks you (KB-3740). It learns question openers with the sentence steps. A new check (KB-3800): well-formed question, right question word for the gap.

Now: waiting. The check is written down, not run.

Where it lives

Inside brainiac itself, no separate copy. Each step is tried on a copy of the brain, behind a switch that is off by default.

1. The dream

Read it lots of storybooks. Over time it should start to wonder, and ask “why?” by itself.

2. The learning loop

One circle, over and over: read, keep the pieces, notice what is missing, ask, learn the answer, and tidy up while resting.

3. The steps

The plan climbs one step at a time; some steps run side by side.

donebeing built or checkedwaiting

Day-dreaming was tested on paper first. First small test (1 story): replaying beat a pretend replay on pairs it had heard, not on pairs it never heard. The bigger test comes after the quota reset.

4. Where we are now

We read it a story and, word by word, ask it to guess the next word.

Same story: better, because it remembers that story, not because it understands. New story: not better yet. The bigger checks, after more stories, are not read yet.

5. Three snags

It stops listening after 200 characters

Long lines get cut, so it never hears their ends. A fix is built and tested behind a switch (off by default; when on, it hears lines up to 1000 characters). The independent check is waiting.

Story words lost to the cut (a line's first 200 letters count, its "max says" start too): baby stories 0 %, preschool stories 3.28 %, grade-school stories 6.12 %.

It counts its own notes as heard

When brainiac does something, it writes a note about it. Those notes were counted as fed to it, but it never heard them. That stopped the reading run. Filed, not fixed yet.

Two identical runs end a hair apart

Two runs of the same program on the same input end a hair apart. This is older than the new code. One guess, not tested yet: the order things are visited, or timing.

6. What's next

  1. Check the long-line fix and fix the note counting, then finish the story run and see if new stories go better.
  2. Check the practice-story tool, then write real practice stories.
  3. Run the bigger day-dream test, then teach it to notice gaps and ask.
