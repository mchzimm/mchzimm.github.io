4b. The road in detail: Toddler → Mouse → Preschool (facts only)

Every box is one thing to solve. Arrows = "needs this first". Click a box: what we measured, and the proof that closes it. Feelings (Chimp) left out on purpose: this road is for factual chat only.

🔒 A box only turns green when ALL of these hold
  1. 📏 The bar is written down before the test runs (never moved after).
  2. 🎲 It beats a fake version (sham / shuffled control) by more than normal run-to-run wobble.
  3. 🔨 Breaking the new code on purpose makes the test fail (falsify stub, rebuilt).
  4. 🧪 Test questions are new to it and cannot be answered by spotting a taught cue word.
  5. 🔁 Same answers after a clean stop and restart.
  6. 🟢 It actually happens in the live brain (count > 0), not only in the test lab.
  7. 🛡️ Old lessons are not harmed.
done partly open blocked purple = being worked on now dark brown = next ⭐ gate = biggest unlock
🧭 Strategy
1. Work the ▶ start here boxes first: everything they need is already done, so they can run side by side.
2. The purple 1…5 path is the shortest way to Preschool: make story answers mostly right (T8) → let a typed live question reach the answer path (T10, the biggest unlock) → right short who/what/where/why answers (P6) → answer stories in its own words (P9) → pass the baby and pre-K story tests (P12).
3. A box is green only when nothing is owed: lab-only results stay yellow until the live brain shows them.
